# 📚 Project Glossary

Common terms and concepts used within the codebase.

| Term | Definition |
| :--- | :--- |
| **AsyncCubit** | A base class for Cubits that simplifies handling of asynchronous operations (Loading, Success, Failure). |
| **Base CRUD** | A pattern/utility for standardizing Create, Read, Update, and Delete operations against an API. |
| **BaseModel** | The top-level data wrapper for API responses, handling status, message, and data mapping. |
| **FullScreenLoadingManager** | A global utility for showing/hiding a blocking loading overlay using `ValueNotifier`. |
| **Go** | A centralized utility for navigation, wrapping `Navigator` or standard routing. |
| **Helpers** | A utility class for common tasks like FCM tokens, status bar color, and sharing. |
| **IconWidget** | A custom wrapper for icons supporting IconData, SVG, Network, Lottie, and Assets. |
| **Injector** | The service locator (GetIt) used for Dependency Injection. |
| **Mason** | The code generation tool used to scaffold new features following the project architecture. |
| **RTL-First** | A design approach prioritizing Right-to-Left languages (Arabic), using `start`/`end` instead of `left`/`right`. |
| **Spec Kit** | The documentation system used to define specifications, rules, and plans for the project. |
